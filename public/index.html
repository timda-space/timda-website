Out of character

TIMDA is a hub for a ring of independently run websites, called Sections, a bit like an old webring. Every Section is its own domain, run by whoever holds its key.

Nothing here is mandatory. A site shows up only when its operator publishes records asking to, and drops off when they remove them. Playing along with the setting is optional too.

Run a site? Dock it. Or take a random wormhole to a docked Section.
